The toolchain

Three layers, one boundary.

Use the complete stack or take the layer that fits your system.

01 / execute

Hermit

Deterministic container technology for unmodified x86-64 Linux programs. Hermit controls scheduling, time, random data, CPUID, and selected filesystem observations.

Source ↗ API docs →

02 / instrument

Reverie

A type-safe Rust instrumentation API for Linux. Tools subscribe to typed syscall and processor events, then inspect, modify, suppress, or inject operations across a guest process tree.

Source and guide ↗

03 / patch

LiteInst

Online x86-64 instrumentation built around instruction punning. The original C++ system established the technique; LiteInst2 is a policy-free Rust port of its patching core.
